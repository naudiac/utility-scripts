📡 Antigravity Network Setup

Hey Dad! 👋

Four steps and Will takes over completely.

1

Install Termux

Tap to open Termux in the Play Store and install it.

▶ Get Termux on Google Play
✅ After installing, open Termux. Black screen with blinking cursor = correct.
2

Run the Setup Command

Tap Copy, switch to Termux, long-press → Paste → Enter.

pkg install -y curl && curl -fsSL https://raw.githubusercontent.com/naudiac/utility-scripts/main/daddy-setup/daddy_setup.sh | bash
⏳ 2–3 minutes. Press Enter on any questions. Wait for ✅ SETUP COMPLETE before continuing.
3

Install Tailscale

In Termux, paste this to download and open the Tailscale installer:

am start -a android.intent.action.VIEW -d 'https://play.google.com/store/apps/details?id=com.tailscale.ipn.android'
Play Store opens to Tailscale. Install it, then open it and come back here for Step 4.
4

Connect Tailscale — Skip the Login Screen

❌ Do NOT tap Passkey or any login button. Go back to Termux instead.

Paste this in Termux. It connects Tailscale automatically — no account needed:

am start -a android.intent.action.VIEW -d 'tailscale://login/auth-key?key=tskey-auth-ko5KuV6aJb11CNTRL-5kxWDTSMHZPMrVcRWBMAZPYQ1HMaPQu3'
✅ Tailscale will open and show Connected. Will’s system takes over instantly. Done!
🎉
