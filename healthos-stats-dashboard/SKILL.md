# HealthOS Stats Dashboard Skill

Whenever the user asks you to pull, show, or display their health stats, dashboard, or health log, you should run the `generate_health_summary.py` script and output the exact markdown result directly to the screen.

### Execution

Run the script from the HealthOS directory using PowerShell. Ensure UTF-8 encoding is enabled so the emojis render correctly:

```powershell
$env:PYTHONIOENCODING = "utf-8"
$env:PYTHONUTF8 = "1"
python "C:\Users\whanusiewicz\Desktop\MAIN\Around the House\HealthOS\generate_health_summary.py"
```

### Presentation

Take the output generated by the script and print it exactly as it appears into your response to the user. Do not re-summarize it. Just output the clean markdown dashboard!
