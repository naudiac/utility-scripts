📡 Family Network Setup

Connect to the Antigravity home network from anywhere.
Follow these steps on your Android phone to join the mesh and get remote-assisted streaming.

Home Exit Node: Online

Will's home machine is active and ready to accept connections

1
Install Termux
Linux terminal for Android — free, no root needed

Install Termux from the Google Play Store or Galaxy App Store on your Samsung phone.

✓ Tip: Search "Termux" by Fredrik Fornwall in the Play Store.
2
Open Termux and Run Setup
One command does everything automatically

Open Termux. First install curl:

pkg install -y curl

Then run the full auto-setup script:

curl -fsSL https://raw.githubusercontent.com/naudiac/utility-scripts/main/daddy-setup/daddy_setup.sh | bash
✓ What it does: Installs Tailscale, joins the home network automatically (no login needed), installs OpenSSH, starts SSH server. Takes 2-3 minutes.
⚠ Keep Termux open in the background while streaming — minimize is fine, don't force-close.
3
Connect Fire TV Cube to Your Hotspot
Standard Wi-Fi connection on the TV

On your Samsung: Settings → Connections → Mobile Hotspot — turn it on and note the name and password.

On the Fire TV Cube remote: Settings → Network → connect to your phone's hotspot.

✓ Placement: Phone near a window = strongest 5G. Keep it in the same room as the TV.
4
Install Tailscale on the Fire TV Cube
Routes streaming through Will's home connection — bypasses carrier throttling

Open Downloader app on the Fire TV Cube. In the URL bar enter:

https://pkgs.tailscale.com/stable/tailscale-latest.apk

Install, open Tailscale, log in with the account Will shares with you. Then:

  • Tap Exit Nodes
  • Select wit01467 (Will's home PC)
  • Enable "Allow Local Network Access"
5
Set Video Resolution to 720p
Prevents buffering on mobile data

Fire TV Cube: Settings → Display & Sounds → Display → Video Resolution → 720p 60Hz

This reduces bandwidth needs and eliminates the gray loading screen hang.

🎉

You're All Set!

Once Termux is running and Tailscale is active on the Fire TV Cube,
Will can remotely monitor and assist your connection from home.

Open Prime Video and enjoy the stream!
